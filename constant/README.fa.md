# بسته constant (`/constant`)

این دایرکتوری فقط برای قرار دادن **تعاریف ثابت** قابل استفاده مجدد سراسری استفاده می‌شود و شامل هیچ منطق تجاری یا وابستگی نمی‌باشد.

## فایل‌های فعلی

| فایل                   | توضیحات                                                                  |
|----------------------|---------------------------------------------------------------------|
| `azure.go`           | تعریف ثابت‌های سراسری مرتبط با Azure، مانند `AzureNoRemoveDotTime` (کنترل زمان قطع حذف `.`).         |
| `cache_key.go`       | رشته‌های فرمت کلید کش و ثابت‌های فیلدهای مرتبط با Token، یکسان‌سازی قوانین نام‌گذاری کش.                                    |
| `channel_setting.go` | کلیدهای تنظیمات سطح کانال، مانند `proxy`، `force_format` و غیره.                          |
| `context_key.go`     | تعریف نوع `ContextKey` و همچنین کلیدهای ثابت متنی که در کل پروژه استفاده می‌شوند (زمان درخواست، اطلاعات مرتبط با Token/Channel/User و غیره). |
| `env.go`             | متغیرهای سراسری مرتبط با پیکربندی محیط، که در مرحله راه‌اندازی بر اساس فایل پیکربندی یا متغیرهای محیطی تزریق می‌شوند.                                     |
| `finish_reason.go`   | مجموعه ثابت‌های رشته‌ای `finish_reason` بازگشتی از درخواست‌های OpenAI/GPT.                           |
| `midjourney.go`      | کدهای خطا و ثابت‌های عملیات (Action) مرتبط با Midjourney و جدول نگاشت مدل به عملیات.                            |
| `setup.go`           | نشان می‌دهد که آیا پروژه نصب اولیه را تکمیل کرده است (مقدار بولی `Setup`).                                       |
| `task.go`            | ثابت‌های پلتفرم و عملیات وظیفه (Task) مختلف و جدول نگاشت مدل و عملیات، مانند Suno، Midjourney و غیره.                     |
| `user_setting.go`    | ثابت‌های کلیدی تنظیمات کاربر و همچنین انواع اعلان (Email/Webhook) و غیره.                                    |

## قراردادهای استفاده

1. بسته `constant` **فقط می‌تواند توسط بسته‌های دیگر ارجاع داده شود** (import)، **ارجاع به سایر بسته‌های سفارشی درون پروژه در این بسته ممنوع است**. در صورت نیاز، فقط ارجاع به **کتابخانه استاندارد Go** مجاز است.
2. نوشتن هر کد منطق مرتبط با فرآیندهای تجاری، عملیات پایگاه داده، فراخوانی سرویس‌های شخص ثالث و غیره در این دایرکتوری مجاز نیست.
3. هنگام افزودن انواع جدید، لطفاً نام‌گذاری معنایی واضح را حفظ کنید و در جدول **فایل‌های فعلی** این README توضیحات را اضافه کنید تا اعضای تیم بتوانند به سرعت از کاربرد آن مطلع شوند.

> ⚠️ نقض قراردادهای فوق منجر به جفت‌شدگی غیرضروری بین بسته‌ها می‌شود و بر نگهداری و تست‌پذیری کد تأثیر می‌گذارد. لطفاً قبل از ارسال کد، خودتان بررسی کنید.
